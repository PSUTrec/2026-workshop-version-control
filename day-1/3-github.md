# What is GitHub?

As discussed in the previous modules, `git` is a software tool for automating some aspects of version control.

**GitHub** is a website that provides a way to store code that is versioned with `git` in the cloud, and provides a GUI for common `git` commands.

We will use GitHub to get started with `git`, then move on to using `git` through the command line and syncing our local work with GitHub.
